# ゲーム株価 × Google検索トレンド 比較サイト

ゲーム会社の株価と、その会社のゲームタイトルに対するGoogle検索トレンド指数を同一グラフで比較できるWebアプリです。

## 機能

- 会社・期間を選択して株価を表示
- プリセットのゲーム名、または任意のキーワードを入力してGoogle検索トレンドを表示
- 複数ゲームのトレンドを同時に重ねて比較
- 株価（左軸）とトレンド指数0〜100（右軸）のデュアル軸グラフ

## 必要環境

- Python 3.10 以上
- Node.js 18 以上
- npm

## セットアップ・起動方法

### 1. バックエンドを起動する

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

起動後、`http://localhost:8000/docs` でAPIドキュメントを確認できます。

### 2. フロントエンドを起動する（別ターミナル）

```bash
cd frontend
npm install
npm run dev
```

起動後、ブラウザで `http://localhost:5173` を開きます。

## 使い方

1. **会社を選択** — ドロップダウンからゲーム会社を選ぶ
2. **期間を指定** — 開始日・終了日を入力する（例: 2022-01-01 〜 2023-12-31）
3. **ゲームを追加** — 以下のいずれかの方法でゲームを追加する
   - プリセットから選択してボタンを押す
   - テキストボックスに任意のゲーム名・キーワードを入力してボタンを押す
4. 追加したゲームはタグとして表示される。×で削除できる
5. **グラフを見る** — 株価（青線）と各ゲームの検索トレンド（色分けされた線）が同時に表示される

## API エンドポイント

| メソッド | パス | 説明 |
|---|---|---|
| GET | `/companies` | 対応会社の一覧 |
| GET | `/companies/{id}/games` | 指定会社のプリセットゲーム一覧 |
| GET | `/stock?ticker=&start=&end=` | 株価データ（週次・終値） |
| GET | `/trends?keyword=&start=&end=` | Google検索トレンドデータ（週次・0〜100） |

## 注意事項

- Google Trendsは非公式APIを使用しているため、短時間に大量リクエストを送るとレートリミットが発生する場合があります
- 株価データはYahoo Financeから取得しています（東証銘柄は `.T` サフィックス）
- トレンドデータは日本（geo=JP）のデータを取得しています
