# ゲーム株価 × Google検索トレンド 比較サイト

ゲーム会社の株価と、その会社のゲームタイトルに対するGoogle検索トレンド指数を同一グラフで比較できるWebアプリです。

## 機能

- 会社・期間を選択して株価を表示
- プリセットのゲーム名、または任意のキーワードを入力してGoogle検索トレンドを表示
- 複数ゲームのトレンドを同時に重ねて比較（最大5件）
- 株価（左軸）とトレンド指数0〜100（右軸）のデュアル軸グラフ

## Vercel へのデプロイ（推奨）

URLを開くだけで使えるようにするには Vercel へデプロイします。無料で利用可能です。

1. [vercel.com](https://vercel.com) にサインアップ（GitHub アカウントでログイン可）
2. ダッシュボードで **Add New → Project** を選択
3. このリポジトリ（`minahood/stockprice_research`）を選択してインポート
4. 設定はそのままで **Deploy** を押す
   - Framework: **Next.js**（自動検出）
   - 環境変数: **不要**
5. デプロイ完了後に発行された URL をブラウザで開く

> **注意**: Google Trends は非公式APIを使用しているため、Vercel のサーバーからのリクエストがレート制限される場合があります。その場合はエラーメッセージが表示されます。

## ローカルで起動する場合

### 必要環境

- Node.js 18 以上
- npm

### 起動方法

```bash
npm install
npm run dev
```

起動後、ブラウザで `http://localhost:3000` を開きます。

## 使い方

1. **会社を選択** — ドロップダウンからゲーム会社を選ぶ
2. **期間を指定** — 開始日・終了日を入力する（例: 2022-01-01 〜 2023-12-31）
3. **ゲームを追加** — 以下のいずれかの方法でゲームを追加する
   - プリセットから選択してドロップダウンを操作する
   - テキストボックスに任意のゲーム名・キーワードを入力して「追加」ボタンを押す（Enterキーでも追加可能）
4. 追加したゲームはタグとして表示される。×で削除できる
5. **グラフを表示** ボタンを押すとグラフが描画される

## API エンドポイント

| メソッド | パス | 説明 |
|---|---|---|
| GET | `/api/companies` | 対応会社の一覧 |
| GET | `/api/companies/{id}/games` | 指定会社のプリセットゲーム一覧 |
| GET | `/api/stock?ticker=&start=&end=` | 株価データ（週次） |
| GET | `/api/trends?keyword=&start=&end=` | Google検索トレンドデータ（週次・0〜100） |

## 注意事項

- Google Trendsは非公式APIを使用しているため、短時間に大量リクエストを送るとレートリミットが発生する場合があります
- 株価データはYahoo Financeから取得しています（東証銘柄は `.T` サフィックス）
- トレンドデータは日本（geo=JP）のデータを取得しています
